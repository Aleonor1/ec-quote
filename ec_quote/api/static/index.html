Chatul de ofertă ec-quote

Pagina aceasta există doar cu EC_QUOTE_DEMO=1. Deschideți chatul din colțul din dreapta jos.

Cu motorul demonstrativ puteți încerca:

  • orice mesaj: răspuns cu text și butoane;
  • ofertă: oferta rămâne în așteptarea aprobării, clientul vede doar un anunț neutru;
  • coleg: conversația este predată unui om;
  • un fișier PDF, PNG, JPG, WEBP sau SVG: răspuns cu imagine.
